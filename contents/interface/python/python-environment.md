# Python 개발환경 설정

## Python 언어 인터프리터 설치

**Python 인터프리터** 설치 파일을 [[여기]](https://www.python.org/downloads/)에서 다운로드하여 설치합니다.

Windows 환경을 사용하는 경우 `C:\Utils\Python3`에 설치하는것을 가정합니다.

## Visual Studio Extension 설치

- 기본 Extension 설치

    아래의 Extension을 설치합니다.

    ![python-install](/assets/images/python-001.png)

- 또는 **Python Extension Pack**을 설치하여도 됩니다.

    ![python-install](/assets/images/python-002.png)

    **Python Extension Pack**에는 다음과 같은 Extension이 포함되어 있습니다.

    - **autoDocstring - Python Docstring Generator**

    - **Jinja**

    - **IntelliCode**

    - **Python Environment Manager**

    - **Python**

    - **Django**

    - **Python Indent**
