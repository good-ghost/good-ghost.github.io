# Oracle Cloud에 웹 터미널로 접속하는 방법

1. Oracle Cloud의 웹 콘솔에 접속합니다.

    `Dashboard`에서 **Instances**를 클릭합니다.

    ![VM Web Terminal](/assets/images/oracle-cloud-term-01.png){: width="600" }

2. `Instances` 섹션에서 **Instances**를 클릭합니다.

    ![VM Web Terminal](/assets/images/oracle-cloud-term-02.png){: width="600" }

3. `Compute > Instances > Instance Detail` 화면에서

    아래로 스크롤하여 `Resources` 섹션에서 **Console Connection**을 클릭합니다.

    ![VM Web Terminal](/assets/images/oracle-cloud-term-03.png){: width="600" }

4. `Console Connection` 섹션에서 **Launch Cloud Shell connection** 버튼을 클릭합니다.

    ![VM Web Terminal](/assets/images/oracle-cloud-term-04.png){: width="600" }

웹 터미널로 접속한 후에 방화벽 설정을 변경합니다.
